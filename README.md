# SMS2Hook

Android-приложение, которое пересылает **входящие SMS** на любой HTTP‑вебхук по
настраиваемым **пресетам**. В комплекте готовые пресеты для **Telegram**, **Gotify**,
**Discord** и **WhatsApp**, плюс произвольный webhook. Написано на **Kotlin + Jetpack Compose**.

> ⚠️ Из‑за политики Google Play приложения с доступом к SMS почти невозможно
> опубликовать в Play. Приложение рассчитано на **личную установку APK (sideload)**.

## Возможности

- Перехват всех входящих SMS (в т.ч. длинных/составных — собираются в одно).
- Пересылка на **несколько адресатов одновременно** (несколько включённых пресетов).
- HTTP‑метод **GET** или **POST**.
- Тело запроса: **форма** (x-www-form-urlencoded), **JSON**, **raw** или без тела.
- Произвольные **заголовки** и **поля** (кнопка «＋ Добавить» → имя + значение).
- Шаблоны с переменными: `{sender}`, `{sender_phone}`, `{msg}`, `{sim}`, `{date}`, `{time}`, `{datetime}`, `{timestamp}`.
- Автоматическое URL‑кодирование значений в URL и JSON‑экранирование в теле JSON.
- **Пресеты**: создание / редактирование / дублирование / удаление / включение.
- **Фильтры**: пересылать все, только совпадающие или кроме совпадающих (по отправителю и тексту).
- **Надёжная доставка**: очередь и повтор при потере сети (WorkManager, экспоненциальный backoff).
- **Журнал доставки** с кодом ответа и ошибкой.
- Кнопка **«Тест»** — отправляет пробный запрос без ожидания реального SMS.
- Общий выключатель, подсказки по разрешениям и энергосбережению.
- Токены и пресеты хранятся **только на устройстве** (резервное копирование отключено).

## Получить APK (сборка в CI)

APK собирается автоматически через **GitHub Actions** (workflow `.github/workflows/build.yml`).

- **Из вкладки Actions:** откройте последний запуск → раздел **Artifacts** → скачайте
  `sms2hook-debug-apk` (это `app-debug.apk`).
- **Через релиз:** создайте тег вида `v1.0` — APK автоматически прикрепится к GitHub Release.

```bash
git tag v1.0
git push origin v1.0
```

## Установка на телефон

1. Скопируйте `sms2hook-1.0.4.apk` на телефон.
2. При установке разрешите «Установку из неизвестных источников» для вашего файлового
   менеджера/браузера.
3. Откройте приложение и на главном экране:
   - нажмите **«Выдать разрешения»** (приём SMS, контакты — опционально, уведомления);
   - нажмите **«Настроить батарею»** и отключите оптимизацию для приложения (важно для
     фоновой доставки);
   - включите нужные пресеты и общий переключатель **«Пересылка SMS»**.

## Настройка пресетов

### Telegram
1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите **BOT_TOKEN**.
2. Узнайте свой **CHAT_ID** (напишите боту и откройте
   `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`, поле `chat.id`).
3. В пресете **Telegram** замените `<BOT_TOKEN>` в URL и `<CHAT_ID>` в поле `chat_id`.
   Метод `POST`, тело `Форма`, поля `chat_id`, `text`.

### Gotify
1. В Gotify создайте приложение и получите **APP_TOKEN**.
2. В пресете **Gotify** укажите адрес сервера в URL (`https://<ваш-сервер>/message`) и
   вставьте токен в заголовок `X-Gotify-Key`. Метод `POST`, тело `Форма`.

### Discord
1. В нужном канале: **Настройки канала → Интеграции → Вебхуки → Создать вебхук** →
   **Копировать URL вебхука**.
2. Вставьте этот URL целиком в поле URL пресета **Discord**. Метод `POST`, тело `JSON`:
   `{"content":"📩 SMS от {sender} ({sender_phone}):\n{msg}"}`.
   `{msg}` экранируется под JSON автоматически.

### WhatsApp
WhatsApp не даёт простого вебхука для отправки. Самый лёгкий путь для личных уведомлений —
бесплатный сервис **CallMeBot** (встроенный пресет **WhatsApp (CallMeBot)**):
1. Добавьте в контакты номер **+34 621 331 709**.
2. Отправьте ему в WhatsApp сообщение: `I allow callmebot to send me messages to this number`.
3. В ответ придёт ваш **API_KEY**.
4. В пресете заполните `phone` (ваш номер, только цифры с кодом страны) и `apikey`.
   Метод `GET`, поля уходят в query.

**Альтернативы (более «промышленные»):**
- **Twilio WhatsApp**: `POST https://api.twilio.com/2010-04-01/Accounts/<SID>/Messages.json`,
  тело `Форма` с полями `From=whatsapp:+…`, `To=whatsapp:+…`, `Body={msg}`, заголовок
  `Authorization: Basic <base64(SID:TOKEN)>`.
- **Meta WhatsApp Cloud API**: `POST https://graph.facebook.com/v20.0/<PHONE_NUMBER_ID>/messages`,
  тело `JSON`, заголовок `Authorization: Bearer <TOKEN>`. Учтите правило 24‑часового окна и
  шаблоны сообщений.
Любой из вариантов настраивается как обычный пресет (метод + URL + заголовки + поля/тело).

### Произвольный webhook
Соответствует вашему эскизу: выбор метода, URL и кнопка «＋ Добавить», которая добавляет
строку «имя + значение». Для GET поля уходят в query‑строку URL, для POST — в тело
(форма/JSON/raw).

### Переменные шаблонов
| Переменная | Значение |
|---|---|
| `{sender}` | Имя из контактов, иначе адрес отправителя |
| `{sender_phone}` | Номер/адрес отправителя (как пришёл) |
| `{msg}` | Текст сообщения (`{message}` — синоним) |
| `{sim}` | Индекс SIM/слота (dual‑SIM), если доступен |
| `{date}` `{time}` `{datetime}` | Дата/время получения |
| `{timestamp}` | Метка времени в миллисекундах |

## Локальная сборка

**Android Studio (проще всего):** откройте папку проекта и дождитесь синхронизации Gradle
— APK появится в `app/build/outputs/apk/debug/`.

**Командная строка (нужны JDK 17 и Gradle 8.7+):**
```bash
gradle assembleDebug
```

> Gradle wrapper в репозиторий не коммитится. В Android Studio он создаётся автоматически
> при первом открытии; для CLI используйте установленный Gradle 8.7+ (или сгенерируйте
> wrapper командой `gradle wrapper`). CI сам ставит Gradle 8.7.

## Технологии

Kotlin 2.0 · Jetpack Compose (Material 3) · Room · WorkManager · DataStore · OkHttp · Gson
AGP 8.5 · Gradle 8.7 · minSdk 26 (Android 8.0) · targetSdk 33 · compileSdk 34.

## Структура

```
app/src/main/java/com/smswebhook/
├── sms/SmsReceiver.kt        # приём SMS (BroadcastReceiver)
├── work/                     # WorkManager: очередь и повтор отправки
├── net/WebhookSender.kt      # построение и выполнение HTTP-запроса (OkHttp)
├── template/TemplateEngine.kt# подстановка переменных + кодирование
├── data/                     # Room (пресеты, журнал), DataStore, дефолтные пресеты
├── model/Models.kt           # модели и константы
└── ui/                       # Compose: список, редактор пресета, журнал, настройки
```

## Приватность

Приложение не отправляет данные никуда, кроме URL, которые вы сами указали в пресетах.
Пресеты (включая токены) хранятся в приватной базе приложения; резервное копирование в
облако отключено (`allowBackup=false`).
